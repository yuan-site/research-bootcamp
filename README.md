# 小論文寫作特訓班

copyrihgt@臺北市立陽明高中王聖淵老師

純 HTML / CSS / JavaScript 的互動教學網站，不需要安裝套件或資料庫。

## 開啟與部署

直接以瀏覽器開啟 `index.html` 可以使用。建議以固定網址提供網站，讓瀏覽器儲存位置一致。任何靜態網站主機都可部署 此儲存庫中的四個網站檔案。

本機伺服器可在此資料夾執行 `python -m http.server 4173`，再開啟 `http://localhost:4173`。電腦需先有 Python；網站本身不依賴 Python。

## 功能

- 11 個主題、70 個小步驟；共同基礎、實徵與非實徵路線。
- 每一步提供概念、例子、練習、提示、教師指引及自我檢查。
- 11 題主題觀念檢核，可重試並儲存紀錄。
- 練習自動儲存、閱讀與完成度分開；修改作答會撤銷該步完成標記。
- 資料整理與分析的任務可記錄理由後標為不適用。
- 作品集中瀏覽、Markdown 匯出、JSON 進度備份及驗證後匯入。
- 回填結果、結論、限制與參考資料，完成最後自檢。
- CSV 空白表單、Excel 排序教學、描述統計練習器。
- 桌面與手機響應式版面，鍵盤操作與列印作品。

## 修改內容

- `index.html`：網站固定標題、頁首與頁尾。
- `style.css`：顏色、字型與響應式版面。
- `course.js`：完整主題與課程資料，可直接編輯。
- `app.js`：畫面與互動邏輯。

## 資料與限制

使用瀏覽器 localStorage 儲存，不包含帳號、跨裝置同步、線上批改或教師後台。切換裝置、網址或清除瀏覽資料前，先下載 JSON 備份；Markdown 只供閱讀與修改，不能重新匯入進度。無法本機儲存時網站會顯示提示。

完稿自檢依作答、檢核與自我確認紀錄運作，不會自動評分研究品質。圖表需依自己的研究資料製作，本站的示例與計算器不會產生或代填研究發現。

課程為依使用者提供的書籍主題脈絡所作的原創教學改寫，沒有部署來源掃描 PDF。關於來源與補充設計的說明在網站「關於與資料來源」。
